# 工具一览（`tools\` 里有什么、什么时候用）

> **本文只讲"对外使用者会用到哪些脚本"**。想改这个仓库 → `CONTRIBUTING.md`。
> 全部命令都在**工作区根目录**下跑；脚本自己会推导仓库根，不用先 `cd` 到 `tools\`。

## 1. 你一定会用到的四个入口

| 命令 | 它干什么 | 什么时候跑 |
| --- | --- | --- |
| `node tools\self-check.mjs` | **全工作区自检**：运行时、启动链、preset、文档一致性、结构不变量。**只读**，不改任何东西；加 `--deep` 还会跑端到端 | 装完、改完、起不来时 |
| `node tools\pack-new.mjs --list` | **打包预检**：只打印"将会包含哪些 / 排除了哪些（带原因）"，不写任何文件 | 想给别人一份之前 |
| `node tools\pack-new.mjs --out <目录或 zip>` | 把工作区打成**可以交付 / 搬走的包**；打完还会对**产物**再跑一次安全扫描，命中就删包并非零退出 | 要交付时 |
| `node tools\scan-secrets.cjs <文件或目录>` | **发布前安全扫描**（只读）：找真值、凭据形状与不该外露的东西；**命中 = 非零退出**。`--repo` 扫全仓 | 任何东西要发出去之前 |

★ 口径一句话：**"自检绿" ≠ "可以发出去"** —— 能不能发由 `scan-secrets` 说了算，两者是两件事。

## 2. 安装与一次性脚本

| 脚本 | 用途 |
| --- | --- |
| `setup-all.ps1` | 给"刚拿到这个部署包的人"用的一步安装（可交付部署包那条线） |
| `setup-new.mjs` | 交互式填新机器的配置（生成 `config.json` 的那些真值） |
| `check-presets.mjs` | preset 校验：YAML 自检、列名单、`mount` / `probe` 端到端 |
| `structure-snapshot.mjs` | 刷新 `docs\结构快照.md`（**运行后生成**；行数 / 文件数这类**易过期数字**，别手改） |
| `changelog.mjs` | 变更日志：`add` / `amend` / `list` / `check`（落 `docs\变更日志.jsonl`） |

## 3. 启动与关闭

| 脚本 | 用途 |
| --- | --- |
| `start-all.ps1` | 启动器本体（根目录 `一键启动.cmd` 调它）；`-DryRun` 只看会起谁 |
| `stop-all.ps1` | 关闭全部；`-DryRun` 只看会关谁 |
| `dsh-only.ps1` | 只起 DSH 本体（命令行跑；原根目录 `只开DSH.cmd` 入口已于 2026-09-27 撤除） |
| `ensure-bridge.ps1` | 把桥接带回正轨（守护/自愈那一环） |
| `log-run.ps1` | 输出管道的出口 —— ★ **不能删**，删了启动链会断 |

## 4. 回归网与自测（改代码之后跑）

| 脚本 | 守住什么 |
| --- | --- |
| `test-export-a-links.mjs` | 对外副本生成器的**链接 / 硬链接 / 判据力** |
| `test-dsh-stop-autorestart.mjs` | "DSH 真停 ⇒ 自动拉起"这条链的接线与契约 |
| `test-prune-upstream.mjs` | 裁剪脚本的回归网 |
| `test-self-check-qq-moved.mjs` | "QQ 那套已搬到别处"这一状态的回归网 |
| `test-watch-qq-login.mjs` | 掉线告警脚本的回归网 |
| （桥接自己的测试） | `node qq-bridge\scripts\test-all.mjs` —— 桥接子项目的总入口 |

## 5. 其余脚本（开发与运维自用）

下面这些是**这个工作区自己**用的（控制台驱动、面板检查、窗口管理、看板、工具间通信、体积与编码体检等），
对外使用者**不需要**它们；想找某一个时，**看该文件开头的注释** —— 每个脚本的头几行都写着"它是什么 / 什么时候用"。

- 控制台与面板：`control.ps1` · `control-server.mjs` · `control-actions.mjs` · `control-driver.mjs` ·
  `panels.ps1` · `panels-check.ps1` · `panels-refresh.mjs` · `panels-arrival-selftest.ps1`
- 窗口与显示：`list-windows.ps1` · `minimize-windows.ps1` · `windowless.ps1` · `windowless-check.ps1` · `probe-windows.ps1`
- 体检与快照：`cmd-bytes.mjs` · `parse-check.ps1` · `top-level-transient.mjs` · `stall-audit.mjs`
- 内容与补丁：`patch-text.mjs` · `board.mjs` · `board-slim.mjs`
- 网关相关：`snowluma-login.ps1` · `snowluma-log-level.ps1` · `snowluma-inject.ps1`

> ⚠ 这一节**只列名字、不逐个解释**：它们的头部注释才是权威，而且改动频繁 —— 抄一份说明进文档，
> 第二天就会过期（本仓库有"**易过期数字/说明别手抄**"这条硬规矩）。

## 6. 想自己加一个脚本

- 放 `tools\`，**头几行写清"它是什么 / 什么时候用"**（本节第 5 条就是靠这个才敢不逐个解释）；
- 会改仓库状态的脚本，**先支持 `--dry-run` 或 `--list`**（先给人看、再动手）；
- 改完按 `CONTRIBUTING.md` 记一条变更日志。
