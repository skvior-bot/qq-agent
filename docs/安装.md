# 安装与首次启动（面向使用者）

> **本文只讲"从零把它跑起来"**，不讲内部设计与运维。
> · 桥接那一层的安装以**上游 README** 为准：<https://github.com/Derpyu520/qq-bridge>
> · 想改这个仓库、或自己搭一份 → `CONTRIBUTING.md`
> · 许可与第三方归属边界 → `README.md` ＋ 根目录 `LICENSE`

## 0. 你需要准备什么

| 需要 | 说明 |
| --- | --- |
| **Windows 10 / 11** | 启动链是 PowerShell ＋ `.cmd`；**只支持 Windows** |
| **PowerShell 5.1** | 系统自带 |
| **Node.js ≥ 22.13** | 版本下限写在 `qq-bridge\package.json` 的 `engines` 里 |
| **DSH 本体** | 全局 npm 包：`npm i -g @deepseek-ai/dsh`（**不在本仓库里**） |
| **第三方 QQ 网关 SnowLuma** | 从它的 releases 页下 **Windows 完整版 zip**，解压后放成 `SnowLuma\`（**不在本仓库里**） |
| **一个 QQ 号** | 建议用小号 —— 网关是**扫码登录**，扫的就是它 |

## 1. 把工作区放到本地

- 放哪儿都行；**路径别带空格 / 中文更省事**（启动链里全是 PowerShell 与 `.cmd`）。
- ★ **两份东西不在仓库里，要自己放**：
  1. `SnowLuma\` —— 第三方网关，见上表；
  2. `qq-bridge\` —— **上游第三方项目**，按下面第 3 步 clone。
  ⚠ 本仓库**故意不带** `qq-bridge\`（它属于上游作者，且上游未提供许可）。

## 2. 装依赖

- 确认 Node 满足版本下限：`node -v`
- 网关那份 zip 解压到工作区根的 `SnowLuma\`（目录名照原样）。

## 3. 装 DSH 端（preset ＋ MCP）

- 桥接仓库自带一个**幂等**的安装脚本 `setup-dsh.mjs`：它把 agent preset 与 MCP 挂载装进你的 DSH 环境。
- 逐步说明与常见漏项 → 上游的 `qq-bridge\docs\DSH_SETUP.md`（**本文不重写，上游写得更准**）。
- ⚠ **装完 / 改完 preset 或 MCP 之后必须重启 DSH** —— 这类改动不会热生效。

## 4. 填配置

1. 把 `qq-bridge\config.example.json` 复制成 `qq-bridge\config.json`。
   （口径：**模板进仓库、真值不进**。）
2. 网关那边：跑它的启动器 → 用**它自己给出的初始口令**登录它的 WebUI → 扫码登 QQ →
   打开 OneBot 的 WebSocket 服务端与 HTTP API，把**它给出的地址与访问串**抄进 `config.json`。
3. ⚠ `config.json` 里是**真凭据**：**别提交、别外传、别贴进任何文档或聊天**。
   仓库根的 `.gitignore` 已经排除了它。

## 5. 第一次启动

- 根目录双击 **`一键启动.cmd`**（启动和关闭都在它身上）：
  - 菜单 `1` = 全部启动（DSH ＋ 桥接 ＋ 网关）
  - 菜单 `2` = 只登录网关
  - 菜单 `3` = 关闭
  - `一键启动.cmd close` = 关闭全部（加 `-DryRun` 只看它会关谁）
- 只想开 DSH 本体：双击 **`只开DSH.cmd`**。
- DSH 那个窗口里随时输 `e` = 关闭全部、`r` = 重起 DSH。

## 6. 起不来怎么查（按这个顺序）

1. **先看它自己说什么** —— 启动窗口与日志里的报错通常直接点名。
2. **跑一次自检**：`node tools\self-check.mjs`（只读，不改任何东西）。
3. **三类最常见**：
   - 网关**没登录 / 掉线** ⇒ 回到网关界面重新扫码；
   - 配置里那个**服务端口被别的程序占了** ⇒ 换一个空闲的，或在启动器里 `close` 之后重来；
   - DSH 端**没装 preset / 装完没重启** ⇒ 回第 3 步，然后重启 DSH。

> 更细的排查属于桥接与网关自己的事：看上游 `qq-bridge\README.md` 与网关文档。

## 7. 换设备 / 升级

- **换设备要重装 DSH 端**：preset 与 MCP 挂载装在**你的 DSH 环境里**，不在仓库里（所以 clone 一份新的不等于装好了）。
- 升级顺序：**先备份 `config.json`** → 再更新代码 → 再把配置放回去。别反向覆盖。

## 8. 边界与免责

- **只支持 Windows**；"服务器常开"那条路是**实验性的可选路径**（本文不涉及）。
- QQ 侧的自动化使用请**自行确认**符合《QQ 用户协议》与当地法律；网关是独立第三方项目，与腾讯 / QQ 无隶属关系。风险自负。
- 授权与署名边界（哪些是上游的、哪些是本项目创作的）→ `README.md` 与根目录 `LICENSE`。
